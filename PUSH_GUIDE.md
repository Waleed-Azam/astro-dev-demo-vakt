# Push this project to GitHub (3 minutes)

This folder is **already a git repo** (everything committed). You only need to
create the GitHub repo, point this folder at it, authenticate + push.

## Steps

1. Create a **new empty repo** on GitHub (no README): e.g. `Vakt-SaaS-Astro`.
2. In a terminal **inside** this folder, run (replace `YOUR-REPO`):
   ```
   git remote add origin https://github.com/Waleed-Azam/YOUR-REPO.git
   git push -u origin main
   ```
3. Log in when asked: username `Waleed-Azam`, password = a Personal Access
   Token (**Contents: Read and write**) — create one at
   github.com/settings/tokens?type=beta (NOT your GitHub password).

## GitHub Desktop alternative

File → Add local repository → select folder → Publish branch → log in.
